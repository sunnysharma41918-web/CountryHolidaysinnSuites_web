# COUNTRY HOLIDAYS INNSUITES — Discover. Explore. Experience.

A modern, high-converting travel agency landing page built with React, Vite, Tailwind CSS, and Framer Motion. Replicated with exact fidelity from the reference designs.

## Features

- **Pixel-Accurate Hero Section**:
  - Display headline: `DISCOVER. EXPLORE. EXPERIENCE.`
  - Subtitle & interactive booking filter bar (Destination, Persons, Days, Estimate)
  - Left floating user review pill (Matt Boonnee, 5 stars)
  - Right floating location pill (Mardi Himal, Austria • March 23, 2025)
- **Watch Our Popular Mountain Range Clips**:
  - 3 video cards (Poland Tatra Mountains, Divčibare Serbia, Kanisfluh Austria)
  - Interactive video preview modal
  - Save/bookmark counters & duration tags
- **Where Every Stay Feels Like a Dream / Luxury Welcome**:
  - Multi-image resort collage (Dormio Resort Obertraun, Hallstatt Austria)
  - Country tabs (Poland, Serbia, Austria) with hotspot overviews
  - Package links and world-class amenities overview
- **Popular Places For Your Recreation**:
  - 3 recreation cards (Piberstein Lake clear waters, alpine lake reflection, serpentine forest trail)
  - Carousel navigation controls
- **Frequently Asked Questions**:
  - 6 accordion items with animated toggle icons
  - Alpine lake wooden rowboat portrait feature
- **People Speak About Us**:
  - Testimonials from Angel Catherine and Mike Hughes with 5-star ratings
- **Exclusive Travel Deals Newsletter**:
  - Hot air balloon visual and subscription discount flow
- **Interactive Reservation & Estimation Modal**:
  - Instant pricing calculator with customizable add-ons
